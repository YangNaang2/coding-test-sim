이 연습 환경의 SQL 엔진

채점은 SQLite로 합니다. MySQL·Oracle 어느 쪽을 골라도 같은 엔진이며, 문제는 두 DB에서 똑같이 동작하는 표준 문법으로 풀리게 만들었습니다. 자주 쓰는 MySQL·Oracle 함수(DATE_FORMAT, IFNULL, IF, YEAR, MONTH, DATEDIFF, TO_CHAR, TO_DATE, NVL, NVL2, DECODE, TRUNC, MOD, LPAD 등)는 흉내 내어 지원합니다. Oracle의 FETCH FIRST n ROWS ONLY와 FROM DUAL도 됩니다.

실제 DB와 다른 점: 날짜·시각이 문자열로 저장되어 있어 ORDERED_AT <= '2026-11-01'이 11월 1일 0시를 포함하지 않습니다(MySQL은 포함). 정수 ÷ 정수는 몫만 남습니다(MySQL은 소수). 평균은 AVG를 쓰세요. 실전처럼 연습하려면 날짜 범위는 >= 시작일 AND < 다음날로 쓰는 습관을 들이세요.

SELECT 실행 순서

FROM → JOIN … ON → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
  • WHERE에는 집계 함수를 쓸 수 없습니다 → 집계 조건은 HAVING.
  • SELECT 별칭은 ORDER BY에서 쓸 수 있고, WHERE에서는 못 씁니다.
  • GROUP BY를 쓰면 SELECT에는 GROUP BY 컬럼과 집계 함수만 씁니다(MySQL ONLY_FULL_GROUP_BY, Oracle 규칙).
